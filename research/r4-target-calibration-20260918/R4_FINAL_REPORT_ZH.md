# R4：有限目标校准下的安全借用与信息需求

本轮限定研究已完成：冻结算法、完整推导、唯一确认和逐数组审计均已交付。
结果是 **有条件有效、有局部检出收益，同时存在明确代价；并非全面优胜**。
数值来自 `C001/summary.json`，最终审计 `checks/final-result-audit.json` 为PASS。
实际封包状态以 `DELIVERY_MANIFEST.json` 及 `delivery/ARCHIVE_RECEIPT.json` 为准。

## 1. 先回答这次研究实际得到了什么

1. 所需信息是独立、真正零位置的目标校准块 `Ct[Nt,4,6]`，与待检验
   `Z[G,4,6]` 共享目标 κ；桥接还需要独立源库 `Cs[Ns,4,6]` 和有外部依据的
   固定上界 `κt/κs≤D`。目前这些条件只是明确的条件性数据设计，没有认证真实
   SCA3 数据已满足它们；没有读取 GSE320100 或新增患者分析。
2. target-only 直接把 Ct 接入冻结 R3，使用 **Nt** 对应的有限误差参考律。
   这已消除“源库与目标 κ 不匹配”对该基线的影响，不需要知道源漂移；它是
   合法基线，不是新的 R4 原创算法。
3. 固定双库桥把源信息用于降低对数尺度的随机误差，但为安全支付漂移上界的
   保守偏差。收益不是免费的，也不均匀；不能用未拒绝同分布来决定自由合并。
   同 Nt 的效能及固定总预算结果见第4节；不得拿失控 source 的高 Power 作优势。
4. 完整有限样本保护针对 **单一共同／对比噪声比漂移**，同时保留原高斯角向、
   块内共同径向、目标间独立及目标共同研究间形状等条件。D 被低估、任意角向
   变化、目标间依赖、异质目标形状和不共同的管线均值，均不由本次定理解决。
5. 当前 API 的 Nt≥4 是接口条件，不是一般统计最小样本量。新的约化实验结论
   是目标尺度信息不能由无限源样本替代：在明确的平方对数风险下最小最大风险
   阶为 1/Nt。固定精度的必要数目见第3节；不是方向性 PC Power 的样本量公式。
6. 值得保留的研究对象是“受保护借用的局部收益、保守损失与目标信息限制”。
   固定桥、MC 秩和 e-BH 原理本身不新；信息边界的显式特化可核查，但国际
   优先权尚未建立。没有结论支持“已达到某分区 SCI”。

## 2. 模型、实际接口和版本

版本为 **R4-TCB-0.2.0**。唯一正式确认冻结目录是 `C001/`，不是工作树中的
任意新脚本。冻结清单 SHA-256：

`0fa6e578932db51caba13a92ba2e474e234392f6e8771af5ecf1e3b4b517a6a5`

V1、R2、R3、C2 以及先前审查导出均保留。R4 不改其历史结论，不把旧 +6.89434
点、强参照 23.51441 点差距与本批数据串成一条提升曲线。

输入是数值观测块，不包含 truth、真实 shape/κ/δ/radii。每个校准块才是独立
抽样单位，4项研究×6条管线的24个元素不是24个独立校准样本。κ是分布结构的
无量纲比例；无限方差径向模型中不能不加限定地称为两个实际方差的比值。
源／目标校准块的可逆左变换、共同正径向尺度可消去；不是任意原始矩阵可交换。
任意去均值残差、非显著基因和管线对比都不自动成为独立已知零校准。

签名原假设是：4项研究中严格正向（或严格负向）的真实效应不足2项。
共控制2G项正负声明，q=.05；FDR=E[FP/max(1,TP+FP)]，Power 是真实正负声明
被拒绝的比例。全 PC 零假设场景 Power 为未定义，不记为零检出能力。

冻结入口支持 `target_only`、`source_matched`、`source_bound`、`bridge_count`。
缺 Ct 时不会静默切回失配源方法。当前统一包装入口仍要求一个合法 Cs 数组，
即使 target-only 不使用它的数值；这不是 target-only 理论需要源数据。
如果只有 Ct，冻结 R3 的 `evaluate(z,Ct,...)` 就是已校验的数学基线，不能为
满足包装器而编造 Cs。`source_matched` 仍要求真的匹配，不是任意漂移保护。

## 3. 已完成的推导及贡献分级

完整证明在 `R4_THEORY.md`，文献映射在 `R4_RELATED_WORK.md`，审查记录在
`REVIEW_RECORD.md`。C001 内的证明是计算启动时冻结的 T1–T5；工作树最终证明
在计算期间补了同一约化实验的最小最大风险阶推论，没有改确认算法或规则。

设 `Kj=exp(mean(log Aj))/(e/2)`，`Aj/κj~F(4,2)`；设计固定
`λ=Nt/(Ns+Nt)`，定义 `K=D^(1−λ) Ks^(1−λ) Kt^λ`。
其误差律等于 Ns+Nt 个独立 F(4,2) 几何平均的已知有限分布，中心统计量留下
`(δ/D)^((1−λ)/2)` 的收缩。证明只在正尾使用单调性，不错误声称整条实轴收缩
都构成一阶随机支配。沿固定两次形状更新、同 H 的 H11/谱、完整独立参考元组、
方向性部分合取、精确离散 p→e 和 e-BH，得到模型内 FDR≤.05。

这是对校准与参考随机性积分后的保证，不是给定任意已实现校准库的条件保证；
也不是任意分布定理或完整浮点误差认证。已审查的数学推导、代码检查和有限
模拟的证据等级分开。

| 结论 | 精确内容 | 贡献定位及限制 |
|---|---|---|
| T1，target-only | 目标匹配库接续 R3，正确使用 Nt | 继承基线，不称原创 |
| T2，固定桥 | v=π²/3−1；方差 v/(Ns+Nt)，偏差 `(Ns/(Ns+Nt)) log(D/δ)` | 经典枢轴特化，不是最优 Power 规则 |
| T2，收益边界 | 桥的对数 MSE 小于 target-only，当且仅当 `log²(D/δ)<v(1/Ns+1/Nt)` | 精确偏差—方差界，不是数据可见的选择器 |
| T3，完整控制链 | 在声明模型内，正负2G项 FDR≤.05 | 不是新增一般 MC/e-value 定理 |
| T4，局部信息 | 未知漂移为干扰参数时目标有效 Fisher 信息 Nt/2 | 经典计算，仅正则局部无偏及约化实验 |
| T5，有限目标信息 | 两尺度的单块 Hellinger affinity=`sech²(h/4)`，给出完整两点风险与固定宽度区间必要样本量 | 显式可核查特化；优先权未成立 |
| T5推论，最小最大阶 | 对所有基于两库枢轴的估计器，`.1402530099/Nt ≤ R* ≤ 2.2898681337/Nt` | 任意 Ns、单侧无下界漂移；常数非尖锐，不含全部原始矩阵或 PC 决策 |

T5 的一个具体含义：若只用这两个枢轴库构建对所有允许参数都95%覆盖、且每次
对数宽度严格小于 log(r) 的区间，则 r=1.25/1.5/2 时，Nt 至少267/81/28。
这些是 **必要但不充分** 的计数，不是±r相对误差、不限制随机期望宽度，也
不承诺该样本量能达到任何 Power。`checks/information-bounds.json` 保存确定性
积分校验及 Nt=4/12/32/128 的有限两点错误界。不能把该下界扩展为“任何利用
原始矩阵的算法都不可能更好”。

### 4.3 机制判断与推荐

T2精确分解解释C3：`log(D/δ)=log5`带来的保守偏差远大于借用减少的随机误差。
C7虽满足对数MSE改善条件，本批仍未确认Power改善；其区间跨零，不能据此断言
真实Power不改善。联合区间用于量化，而不是筛掉这些不利场景。

**通用研究基线保留target-only；固定桥作为有独立可信、较紧D依据时的条件性
工具保留，不作为自动默认替换。** 不使用测试真δ决定采用哪种模式，也不将
上述MSE阈值偷偷变成已实现的自动门控。当前真实Ct和可信D未认证，两个模式
均不可包装成已验证的SCA3临床应用。

## 7. 论文定位、尚缺证据与本轮停止

可组织为：有限校准、受保护外部借用与目标信息需求的限定模型方法／比较研究。
Methods可用T1–T3及冻结代码；理论边界可用T4–T5；实验必须同时保留窄上界收益、
宽上界损失、D低估失控风险和同总预算比较；Limitations必须包含真实Ct与D缺失、
原始矩阵信息界未建立、非均匀优势及原创性优先权未成立。

或扩充场景得到更好总分。当前执行范围已收束：正确算法与信息边界完成，局部
实用性获得确认；全面优势未建立，领先强方法未实现，通用原创性与真实应用
条件仍缺证据。这些科学限制不是被包装成成功的待办，也不触发无限续算。
